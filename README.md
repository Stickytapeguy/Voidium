<h1>Voidium</h1>

A simple, clean, and powerful coding language built on Rust.

## Channels

* **`stable`** — Main releases meant for normal use.
* **`prerelease`** — Pre-flight builds right before landing on stable.
* **`beta`** — Public preview for testing new stuff.
* **`dev`** — Bleeding edge. Expect broken builds and weird experiments.
